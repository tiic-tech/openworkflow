# M25 Acceptance

- `openworkflow init` creates a concise root `AGENTS.md` OpenWorkflow guide when none exists.
- Existing user-authored `AGENTS.md` content is preserved; OpenWorkflow appends or updates only its marked managed block.
- The managed block is sourced from a maintained versioned template in the package source.
- `openworkflow sync` can refresh the managed block as the template evolves.
- `openworkflow clean` removes only the OpenWorkflow block unless the whole file was generated by OpenWorkflow.
- `openworkflow --help` is useful to agents: it explains first-read files, repo-local `/ow:*` commands, command boundaries, minimal init, and lazy-created artifacts.

Validation target:

```bash
npm run validate
npm run verify:runtime-surface
npm run verify:e2e-workflow
npm run verify:clean
npm run smoke:init
npm run validate:cli
```
