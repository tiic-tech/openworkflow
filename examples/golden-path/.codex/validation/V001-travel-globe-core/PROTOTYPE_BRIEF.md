# Prototype Brief: Validate interactive travel globe as core experience

Validation id: `validation:V001-travel-globe-core`

## Core Question

Can an interactive globe with travel flags, hover photo previews, and a detail panel become the central experience that makes an AI-native travel memory app distinct from a normal photo journal?

## Include

- Rotatable 3D globe
- Three to five sample destination flags
- Hover thumbnails for a flag
- Click detail panel with photo and diary sample

## Exclude

- Login
- Persistence
- Upload
- Production AI integration

## Acceptance Evidence

- A user can rotate the globe and inspect sample destinations.
- A user can hover a flag and see relevant photo thumbnails.
- A user can click into a photo and diary detail experience.
- The prototype is strong enough to decide continue, pivot, stop, or needs_more_evidence.

## Handoff

Build the smallest prototype that can answer the core question. Do not add
production features unless they directly affect the validation result.
